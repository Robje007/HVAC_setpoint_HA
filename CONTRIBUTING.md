# Contributing

Bug reports and proposed improvements are welcome.

## Process

1. Open an issue before starting a substantial change.
2. Create a focused branch or a GitHub fork used only to prepare the contribution.
3. Open a pull request against `main` and explain the reason and user impact.
4. Keep Hassfest, HACS validation, Ruff, and the test suite green.
5. Wait for review and approval from `@Robje007`. Only the repository owner decides whether a contribution is merged.

Direct changes to `main`, force pushes, and branch deletion are protected. A pull request does not guarantee acceptance.

By submitting a contribution, you agree to the contribution grant in [LICENSE](LICENSE).
